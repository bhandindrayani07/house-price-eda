# 🏡 House Price EDA Dashboard

An Exploratory Data Analysis (EDA) project based on the **Ames Housing Dataset** to understand the factors affecting house sale prices using Python and interactive visualizations.

## 🌐 Live Demo

[Open House Price EDA Dashboard](https://house-price-eda-appzaf5whtcl4kbqvuxbssg.streamlit.app/)

## 📌 Project Overview

This project explores housing data to identify patterns, relationships, distributions, and outliers in house prices.

The dashboard allows users to upload the dataset and explore different visualizations interactively.

## 🎯 Objectives

- Understand the distribution of house sale prices.
- Analyze the relationship between house quality and sale price.
- Explore average house prices across neighborhoods.
- Study correlations between numerical features.
- Identify potential outliers.
- Examine missing values and duplicate records.

## 📂 Dataset

- Dataset: Ames Housing Dataset
- Source: Kaggle – House Prices: Advanced Regression Techniques
- Rows: 1,460
- Columns: 81

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## 📊 Dashboard Features

1. Dataset Overview
2. House Price Distribution
3. Sale Price by Overall Quality
4. Average Price by Neighborhood
5. Correlation Heatmap
6. Outlier Analysis
7. Data Quality Analysis
8. Final Insights

## 🔍 Key Findings

- House prices have a positively skewed distribution.
- Overall quality has a strong positive relationship with sale price.
- Living area is another important factor related to house prices.
- Average house prices vary across neighborhoods.
- The dataset contains missing values and potential outliers.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/bhandindrayani07/house-price-eda.git
```

Move into the project folder:

```bash
cd house-price-eda
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

Upload the Kaggle `train.csv` file using the dashboard sidebar.
